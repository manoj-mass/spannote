# Security policy

## Supported versions

SpanNote is pre-1.0. Security fixes go to the latest published minor version.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**.

Include:

- the package and version (for example `@spannote/core@0.1.0`);
- the steps or code that show the problem;
- the impact you expect.

We aim to acknowledge a report within five working days, and we will agree a disclosure date with you
before anything is made public.

Never include real secrets, tokens or personal data in a report or in test data.
